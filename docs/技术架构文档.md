# Onyx 技术架构文档

## 1. 项目概述

**Onyx** (原名 Danswer) 是一个开源的企业级 AI 搜索和知识管理平台,连接公司的文档、应用和人员。它提供功能丰富的聊天界面,支持任意 LLM,并通过 40+ 连接器保持知识和访问控制同步。

### 1.1 核心特性
- 🔍 深度研究团队知识库
- 💬 支持任意 LLM 的安全 AI 聊天
- 🔌 40+ 数据源连接器
- 🤖 自定义 AI 代理(Agents)
- 🔐 企业级安全特性(SSO、RBAC、加密)
- 📊 知识管理和分析
- 🚀 可扩展部署(笔记本、本地、云端)

### 4.2 核心模块详解

#### 4.2.1 Connectors (连接器模块)
**职责**: 从各种数据源拉取和同步数据

**支持的连接器** (47+):
- **协作工具**: Slack, Microsoft Teams, Discord, Zulip
- **文档管理**: Google Drive, Sharepoint, Dropbox, Confluence, Notion
- **项目管理**: Jira, Asana, Linear, ClickUp, Productboard

- **CRM**: Salesforce, HubSpot
- **知识库**: GitBook, Guru, Document360, MediaWiki
- **其他**: Gmail, Web Scraping, Local Files, etc.

**核心接口**:
```python
# backend/onyx/connectors/interfaces.py
class LoadConnector(ABC):
    @abstractmethod
    def load_credentials(self, credentials: dict) -> dict:
        pass
    
    @abstractmethod
    def load_from_state(self) -> GenerateDocumentsOutput:
        pass

class PollConnector(LoadConnector):
    @abstractmethod
    def poll_source(self, start: datetime, end: datetime) -> GenerateDocumentsOutput:
        pass
```

## 8. 核心工作流程

### 8.1 文档索引流程

```mermaid
sequenceDiagram
    participant Admin
    participant API
    participant Worker
    participant Connector
    participant DB
    participant VectorDB

    Admin->>API: 配置连接器
    API->>DB: 保存连接器配置
    API->>Worker: 触发索引任务
    Worker->>Connector: 拉取文档
    Connector-->>Worker: 返回文档
    Worker->>Worker: 文档分块
    Worker->>VectorDB: 生成向量嵌入
    Worker->>DB: 保存文档和块
    Worker->>API: 更新索引状态
    API-->>Admin: 返回索引结果
```

### 8.2 聊天查询流程

```mermaid
sequenceDiagram
    participant User
    participant Web
    participant API
    participant VectorDB
    participant LLM
    participant DB

    User->>Web: 发送消息
    Web->>API: POST /api/chat
    API->>DB: 获取会话历史
    API->>VectorDB: 语义搜索相关文档
    VectorDB-->>API: 返回相关文档块
    API->>API: 构建上下文
    API->>LLM: 调用 LLM (流式)
    LLM-->>API: 流式返回响应
    API-->>Web: SSE 流式响应
    Web-->>User: 实时显示回复
    API->>DB: 保存消息
```

### 8.3 连接器同步流程

```mermaid
sequenceDiagram
    participant Scheduler
    participant Worker
    participant Connector
    participant ExternalAPI
    participant DB

    Scheduler->>Worker: 定时触发同步
    Worker->>DB: 获取连接器配置
    Worker->>Connector: 初始化连接器
    Connector->>ExternalAPI: 拉取增量数据
    ExternalAPI-->>Connector: 返回新文档
    Connector->>Connector: 解析和转换
    Connector-->>Worker: 返回文档对象
    Worker->>DB: 更新文档
    Worker->>DB: 更新同步状态
```

## 9. 安全架构

### 9.1 认证机制
- **Basic Auth**: 用户名/密码
- **OAuth 2.0**: Google OAuth
- **SSO**: OIDC/SAML (企业版)
- **API Key**: 程序化访问

### 9.2 授权模型
- **RBAC**: 基于角色的访问控制
  - Admin: 全局管理员
  - User: 普通用户
  - Limited: 受限用户
- **文档级权限**: 基于连接器的访问控制
- **Persona 权限**: 限制 Persona 访问的文档集

### 9.3 数据安全
- **传输加密**: HTTPS/TLS
- **存储加密**: 凭证加密存储
- **密码哈希**: Argon2
- **Token 管理**: JWT with refresh tokens
